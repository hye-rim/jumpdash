# 점프 대시 ⚡

화면을 **누르면 점프**하는 원터치 달리기(지오메트리 대시식). 네모가 일정한 속도로 자동으로 달리고, 가시를 넘고 블록을 타고 끝까지 간다. 한 번 죽으면 바로 처음부터 다시. 코스 3개. 캐릭터·그림·소리는 모두 이 게임에서 새로 그린 것이다. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 서버 없이 정적 파일만으로 돌아간다(`index.html`).

- **조작**: 화면 아무 데나 누르면 점프(PC 는 스페이스·↑·W·Z·클릭). **누르고 있으면 땅에 닿을 때마다 계속 뛴다**. P 일시정지 · M 소리. 폰은 가로로 돌리면 커진다.
- **움직임**: 속도는 일정(8칸/초). 점프는 꼭대기 2칸·공중에 약 0.4초(3.2칸). 공중에서는 다시 못 뛴다. 계산은 고정 간격(1/120초)이라 같은 입력이면 항상 같은 결과다.
- **장애물**: 가시(닿으면 죽음, 판정은 겉모양보다 조금 작아 아슬아슬하게 피해도 안 죽는다) · 블록(위에 서도 되고 옆·아래에 부딪히면 죽는다) · **점프 패드**(노란 판. 밟으면 3.5칸쯤 튄다) · **우주선 포털**(지나면 우주선이 된다: 누르면 오르고 떼면 내려가며, 천장·바닥에 닿아도 안 죽고 블록·가시에 닿으면 죽는다. 네모 포털로 되돌아온다).
- **박자**: 120 BPM, 한 박자가 정확히 4칸이라 장애물이 박자에 놓인다. 킥·베이스·멜로디가 레벨마다 다르게 나온다(소리는 M 또는 위쪽 버튼으로 끈다). 배경이 박자에 맞춰 깜빡인다.
- **코스**(처음 화면에서 고른다): 1 첫걸음(가시와 낮은 블록, 약 22초) · 2 점프 패드(패드와 계단 블록, 약 29초) · 3 우주선(네모 → 우주선 통로 → 다시 네모, 약 40초).
- **연습 모드**(처음 화면의 🧪): 진행 25%·50%·75%에서 자동으로 저장돼서 죽어도 거기서 다시 시작한다. 기록(최고 %)은 남지 않는다.
- **기록**: 코스별 최고 진행도(%)를 `jdBests` 에 JSON 으로, 로비에 보일 합계(최대 300)를 `jdBest` 에 저장한다. 연습 모드와 튜토리얼은 저장하지 않는다. 죽을 때마다 시도 횟수가 올라간다.
- 화면이 가려지면(탭 전환) 저절로 멈춘다.

규칙은 `logic.js`(화면 없이 Node 로 시험), 코스는 `levels.js`(`S` 가시·`D` 천장 가시·`B` 블록·`P` 패드·`PORT` 포털), 화면·입력·소리는 `game.js`. 시험은 `node --test`(디렉터리): `test/logic.test.js` — 코스 모양, 일정한 속도와 박자, 점프 높이·시간·연속 점프, 가시·블록·패드·포털·우주선의 규칙, 같은 입력이면 같은 결과, 장애물 통과 신호, **해석기(솔버)로 세 코스가 모두 깰 수 있는지**(입력을 0.1초 간격으로만 바꿔도 지나갈 길이 있어야 함), 가만히 있거나 계속 누르고만 있으면 어느 코스도 못 깸.

- **다음에 넣을 만한 것**: 4번째 이후의 어려운 코스(중력 반전 포털·작은 모드·점프 링), 숨겨진 코인, 코스 만들기, 색 고르기.
